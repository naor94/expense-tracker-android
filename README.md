# 💳 Expense Tracker Payment Listener (Android)

אפליקציית אנדרואיד ייעודית, חינמית וקלת-משקל (Native Kotlin) המאזינה להתראות תשלום מ-**Google Wallet / Google Pay** וכרטיסי אשראי ישראליים, ומעבירה אותן אוטומטית ובזמן אמת ל-Webhook של דשבורד מעקב ההוצאות.

---

## ✨ תכונות מרכזיות
- 🚀 **0% צריכת סוללה מורגשת:** מבוסס על שירות מערכת רשמי של אנדרואיד (`NotificationListenerService`).
- ⚡ **תגובה מיידית:** תשלום בקופה נשלח לשרת תוך פחות מ-500 מילי-שניות.
- 🛡️ **חסימת כפילויות:** מנגנון חכם המונע שליחת עסקאות כפולות.
- 📱 **ממשק ניהול:** מסך סטטוס, בדיקת חיבור בלחיצת כפתור ויומן עסקאות אחרונות.
- 🔒 **פרטיות מוחלטת:** האפליקציה פונה ישירות ל-Endpoint שלך ב-Vercel, ללא שרתים חיצוניים או צד-שלישי.

---

## 📥 הורדה והתקנה
1. כנס ללשונית **[Releases](https://github.com/naor94/expense-tracker-android/releases)**.
2. הורד את קובץ ה-**`app-debug.apk`** ישירות לטלפון.
3. לחץ עליו להתקנה (אם צריך, אשר "התקנה ממקורות לא מוכרים").
4. פתח את האפליקציה ולחץ על **"הפעל גישה להתראות בהגדרות"** כדי להפעיל את השירות.
